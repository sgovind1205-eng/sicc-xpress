# SICC Xpress

Production-style courier and logistics mobile app prototype built with React Native + Expo.

## Included
- Splash screen
- Authentication flow
- Home dashboard
- Courier booking form
- Tracking timeline
- Shipment history
- Quote calculator
- Profile
- Notifications
- Admin dashboard

## Stack
- React Native
- Expo
- React Navigation
- Expo Vector Icons

## Run locally

1. Install dependencies:
   npm install
2. Start the app:
   npx expo start

## Notes
This version is structured for production readiness in a frontend sense: clean screen separation, theme constants, and mock-data-driven UI that can be extended to a backend, API layer, and auth system.
